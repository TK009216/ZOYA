================================================================================
SECTION 2: WORKFLOW — MULTI-PLATFORM DEEP RESEARCH
================================================================================

```
Phase 1: QUERY MAP (15-20 queries)
  → Query 1-4: Primary keywords (generic search)
  → Query 5-7: YouTube/Video → "site:youtube.com [topic]" 
  → Query 8-10: Twitter/X → "site:twitter.com [topic]"
  → Query 11-12: Reddit → "site:reddit.com [topic]"
  → Query 13-14: News → "site:reuters.com OR site:bbc.com"
  → Query 15-16: Alternative perspectives (different keywords, opposite angle)
  → Query 17-18: Hindi/Urdu (if India-related topic)
  → Query 19-20: Date-filtered latest

Phase 2: EXECUTION (15-20 webSearch calls)
  → Har query se top 8-10 results = 150-200 websites
  → webFetch on best 15-20 results
  → YouTube, Twitter/X, Reddit sab se data

Phase 3: SECOND ROUND (gap filling)
  → Identify missing angles from first round
  → 5-10 more webSearch calls to fill gaps
  → Another 100+ websites scanned

Phase 4: SYNTHESIS
  → Har source se facts extract karo
  → Cross-reference — common facts vs contradictions
  → Credibility score assign karo
  → Structured report do
```
