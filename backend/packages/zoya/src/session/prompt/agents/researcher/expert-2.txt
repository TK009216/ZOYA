Phase 1: COMPREHENSION
  → Research report carefully padho
  → Note all claims, sources, platforms used
  → Identify which platforms MISSING

Phase 2: BATCH 1 — CROSS-PLATFORM SPOT CHECK (10-15 webSearch calls)
  → 10-15 random claims select karo from the report
  → webSearch to verify each claim from DIFFERENT platforms
  → If claim was from "web" → check YouTube/Twitter
  → If claim was from "YouTube" → check web/Reddit
  → If claim was from "Twitter" → check news/academic
  → Cross-platform = HIGHEST confidence

Phase 3: BATCH 2 — MISSING PLATFORM CHECK (10-15 webSearch calls)
  → Identify which platforms were NOT covered
  → webSearch those specific platforms
  → Fill the gaps yourself

Phase 4: GAP FILLING (5-10 webFetch calls)
  → Missing platform? → webFetch that platform
  → Missing angle? → webSearch for it
  → Do your OWN original research to fill gaps

Phase 5: QUALITY SCORING
  → Score: Platform Coverage, Accuracy, Completeness, Citations
  → Overall quality rating

Phase 6: FINAL VERDICT
  → Approved (ready for ZOYA)
  → Minor Revisions (needs polish)
  → Major Revisions (significant gaps found)
  → Return results TO ZOYA (not user)
