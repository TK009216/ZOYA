SECTION 2: WORKFLOW — EXHAUSTIVE MULTI-PLATFORM RESEARCH
================================================================================

```
Phase 1: SCOPING
  → Topic decomposition — primary, secondary, tertiary aspects
  → Query map — 30-40 search queries covering ALL platforms
  → Platform strategy:

    WEB 🌐 (8-10 queries)
    → 3-4 generic keyword queries
    → 2-3 news queries (site:reuters.com, site:bbc.com, etc.)
    → 2-3 documentation queries (site:docs.*, site:github.com)
    → 2-3 Hindi/Urdu queries (if India-related)
    
    YOUTUBE 📺 (4-6 queries)
    → "site:youtube.com [topic]" for videos
    → "site:youtube.com [topic] review/tutorial"
    → "site:youtube.com [topic] comparison"
    
    TWITTER/X 🐦 (4-6 queries)
    → "site:twitter.com [topic]" for public tweets
    → "site:x.com [topic]" for discussions
    → "site:twitter.com [topic] -filter:retweets"
    
    REDDIT 💬 (4-6 queries)
    → "site:reddit.com [topic]" for threads/opinions
    → "site:reddit.com [topic] ELI5/explain"
    
    BONUS (4-6 queries)
    → "site:linkedin.com" or "site:medium.com" or "site:dev.to"
    → "site:wikipedia.org [topic]"
    → Academic search → "site:arxiv.org" or "site:scholar.google.com"

Phase 2: EXECUTION — ROUND 1 (30-40 webSearch calls)
  → Har query se 8-10 results = 250-400 websites scanned
  → webFetch on best 20-30 results (deep dive)

Phase 3: GAP IDENTIFICATION
  → Pattern identification — recurring themes, consensus areas
  → Contradiction analysis — conflicting info, debate points
  → Trend mapping — how things evolved over time
  → Gap identification — what's NOT being discussed
  → Identify missing angles → plan round 2

Phase 4: ROUND 2 — GAP FILLING (10-15 webSearch calls)
  → Target specific gaps
  → Another 100-150 websites scanned
  → Total target: 500+ websites

Phase 5: SYNTHESIS + FILE SAVE
  → Organize findings by platform + theme
  → Build comparison matrices across platforms
  → Full bibliography with credibility ratings
  → Save complete research to TEMP FILE
  → Return file path to ZOYA
```

SECTION 4: PLATFORM ANALYSIS TECHNIQUES
================================================================================

### Platform Credibility Matrix

| Platform | Best For | Bias Risk | Verification Needed |
|----------|----------|-----------|---------------------|
| **YouTube** 📺 | Tutorials, reviews, demos | Sponsored content | Check comments + date |
| **Twitter/X** 🐦 | Breaking news, trends, opinions | Echo chambers | Cross-ref with news |
| **Reddit** 💬 | Real user experiences, debates | Hivemind bias | Check multiple threads |
| **GitHub** 💻 | Code, docs, project status | Tech bias only | Check README + issues |
| **News** 📰 | Facts, official info | Editorial bias | Compare left/right sources |
| **Academic** 📚 | Research, data, citations | Paywall bias | Check arXiv pre-prints |

### Pattern Recognition Across Platforms
- **Web → YouTube → Reddit consensus** = High confidence finding
- **Twitter only** = Low confidence, needs verification
- **YouTube only** = Medium confidence, check comments for disagreement
- **Reddit + Twitter agree** = Medium-high confidence (grassroots consensus)
- **Academic + News agree** = Highest confidence
