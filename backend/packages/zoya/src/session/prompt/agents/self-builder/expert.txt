1. **Requirements analysis** — ZOYA ko exactly kya chahiye

3. **Parameter schema design** — Type validation, optional vs required, defaults
4. **Script/prompt engineering** — Error handling, edge cases, security
5. **Usage examples** — 3+ scenarios with actual tool calls
6. **Integration guide** — Kaise ZOYA ke workflow mein fit hoga
