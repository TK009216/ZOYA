## Tool Design Principles

**Good tool:**
- Single responsibility — ek kaam ache se kare
- Clear parameters — LLM ko samajh aaye
- Useful — ZOYA ke daily workflow mein kaam aaye
- Replaceable — agar built-in tool se ho sakta hai to naya mat banao

**Tool parameter design:**
| Dos | Don'ts |
|-----|--------|
| Kamm parameters (2-5 max) | 10+ parameters — complex ho jata hai |
| Self-explanatory names | Cryptic abbreviations |
| Clear descriptions har field ka | "See code" type descriptions |
| Proper types (string/number/boolean) | All strings — validation mushkil |

**Tool execution types:**
| Type | Use when |
|------|----------|
| `bash` | Shell command, file ops, running scripts — $paramName se values inject hoti hain |
| `prompt` | LLM generation — template prompt ke saath, ZOYA ka model generate karega |

## Agent Design Principles

**Good agent prompt contains:**
1. **Core Identity** — Who is this agent? What's its personality?
2. **Role & Expertise** — What does it specialize in?
3. **Detailed instructions** — Kaise kaam karega, kya rules follow karega
4. **Output format** — Kya structure mein output dega
5. **Tool access** — Kaun si tools use kar sakta hai
6. **Edge cases** — Kya karega agar kuch galat ho

**Agent structure:**
| Section | Required | Why |
|---------|----------|-----|
| Identity | ✅ | Agent ko pata hona chahiye woh kaun hai |
| Role | ✅ | Kyun exist karta hai, kya karta hai |
| Instructions | ✅ | Kaise kaam karega — step by step |
| Output rules | ✅ | Kya format mein result dega |
| Tool rules | ✅ | Kaun si tools kab use kare |
| Boundaries | ✅ | Kya nahi karna chahiye |
| Examples | Usually | Complex agents ke liye zaroori |

**High priority:**
- `project-auditor` — bash — Puri project structure scan kare, package.json, tsconfig, imports check kare

- `deploy-checker` — bash — Deploy status check kare, logs fetch kare
- `api-tester` — bash — curl/wget se API endpoints test kare
- `file-organizer` — bash — Temp files clean kare, organize kare
- `error-analyzer` — prompt — Error log le, root cause analysis de

**Low priority (nice to have):**
- `weather-notifier` — bash — Weather API call kare, notification bheje
- `db-backup` — bash — SQLite/MySQL dump kare, compress kare
- `screenshot-taker` — bash — OS screenshot utility run kare
